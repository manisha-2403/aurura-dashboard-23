# Personal Finance Dashboard

A modern web application that helps users manage income, expenses, and financial analytics through an interactive dashboard.

## Features

- User authentication
- Add income and expenses
- View transaction history
- Expense categorization
- Dashboard analytics
- Responsive design
- Data visualization

## Tech Stack

Frontend:
- React
- TypeScript
- Tailwind CSS
- Vite

Backend / Services:
- Supabase
- PostgreSQL Database

Tools:
- Git
- GitHub

## Project Structure

src/
 ├── components
 ├── hooks
 ├── routes
 ├── lib
 └── pages

## Installation

Clone repository:

git clone your-repository-link

Install dependencies:

npm install

Run project:

npm run dev
